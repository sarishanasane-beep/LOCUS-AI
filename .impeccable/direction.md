# LOCUS AI Direction Contract

FORM seed key: `brief-pinned:locus-master-2026-10-16`

## THESIS

LOCUS AI makes signal unreliability visible and operable: judges see the same room, packets, estimates, uncertainty, and decisions the engine is computing now.

## OWN-WORLD

A precision spatial-research console rooted in aerospace mission control, scientific plotting, and Swiss technical publishing. Square geometry, sparse high-chroma semantics, and measurement-first typography are binding.

## STORY

Measure → assess → estimate → challenge → compare. The visitor begins with the mechanism already running, can deliberately degrade it, then follows the evidence into intelligence, validation, datasets, and methodology.

## FIRST VIEWPORT

An editorial positioning claim shares the frame with the live 20 × 15 metre room. It must prove this is an operating estimator—not a landing-page promise—before the first scroll.

## FORM

Fixed operational rail, strong ruled grid, border-defined hierarchy, deep neutral ground, Space Grotesk for navigation/editorial voice, IBM Plex Mono only for technical data, cyan for measured/truth signals, lime for LOCUS intelligence, amber/coral for degraded/failure states.

## QUALITY BAR

- Mechanism recognizable in the first viewport.
- Every technical value comes from current backend state or is explicitly labelled configuration.
- No rounded dashboard cards, decorative glass, generic AI gradients, or invented benchmark claims.
- Desktop and mobile retain an obvious task hierarchy and named controls.
- Loading, error, stale link, degraded geometry, and insufficient information remain explicit and recoverable.
